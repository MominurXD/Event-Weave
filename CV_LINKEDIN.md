## LinkedIn project description

Built **EventWeave**, a digital-forensics incident reconstruction platform focused on evidence integrity and explainable analysis. It imports security-event bundles, generates SHA-256 evidence manifests, normalises events into a UTC timeline, correlates users/IPs/hosts/processes/files, detects suspicious activity and records investigation actions in a SQLite audit trail.

Tech: **Python, FastAPI, Pydantic, SQLite, JavaScript, Pytest, Docker and GitHub Actions**.

The project was designed to connect academic Computer Science topics—computer forensics, algorithms, databases and security engineering—with a practical investigation workflow.
